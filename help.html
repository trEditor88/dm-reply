DM 자동 답장 사용 설명서

인스타그램 DM 이 오면 미리 적어 둔 문구로 대신 답장해 주는 사이트입니다. 가입 → 인스타 로그인 → 답장 내용 저장 → 켜기, 네 단계면 됩니다.

차례
  1. 가입하고 로그인하기
  2. 화면 알아보기
  3. 인스타 계정 연결하기
  4. 답장 내용 정하기
  5. 켜고 기록 보기
  6. 이럴 땐 이렇게
먼저 알아 두세요. 자동 답장은 인스타그램 약관에 어긋날 수 있어 계정이 제한될 수 있습니다. 중요한 계정이라면 신중하게 쓰세요.

1. 가입하고 로그인하기

  1. DM 자동 답장 사이트를 엽니다.
  2. 가입 탭을 누릅니다.
  3. 아이디(영문 소문자·숫자·_ 3~20자), 이름, 비밀번호(6자 이상)를 적습니다.
  4. 가입 신청을 누릅니다.
  5. 승인되면 로그인 탭에서 로그인합니다. 승인 전에는 "아직 승인 전이에요" 안내가 나옵니다.

한 번 로그인하면 30일 동안 유지됩니다.

2. 화면 알아보기

위치보이는 것뜻
맨 위PC 연결됨 / PC 꺼짐답장을 실제로 보내는 PC 가 켜져 있는지 알려 줍니다. 꺼져 있으면 답장이 나가지 않습니다.
내 인스타 계정계정 카드연결한 인스타 계정마다 카드가 하나씩 생깁니다. 한 사람당 2개까지 추가할 수 있습니다.
카드 오른쪽 위켜기/끄기 스위치자동 답장·자동 공감을 함께 켜고 끕니다.
카드 안상태 표시, 오늘 답장 N/M · 공감 N/M지금 상태와 오늘 보낸 답장·공감 수입니다. 공감은 켰을 때만 보입니다.

카드 상태 표시

  • 동작 중 — 자동 답장이 돌아가고 있습니다.
  • 꺼짐 / 로그인됨 · 꺼짐 — 꺼 둔 상태입니다. 스위치를 켜면 시작합니다.
  • 로그인 필요 — 인스타에 다시 로그인해야 합니다(3장).
  • PC 꺼짐 — PC 가 꺼져 있어 지금은 답장할 수 없습니다.
  • 오류 — 문제가 생겼습니다. 계속되면 관리자에게 문의하세요.

3. 인스타 계정 연결하기

  1. "계정 추가" 칸에 이름표(예: 내 본계정)를 적고 추가를 누릅니다.
  2. 새로 생긴 카드에서 원격 로그인을 누릅니다. PC 가 인스타 창을 여는 데 20초쯤 걸립니다.
  3. 휴대폰에 인스타 로그인 화면이 보이면, 입력칸을 먼저 화면에서 누른 뒤 아래 글자 칸에 적고 보내기를 누릅니다.
  4. 인스타 비밀번호를 칠 때는 입력 가리기를 켜면 글자가 화면에 보이지 않습니다.
  5. Enter로 로그인합니다. 화면은 누른 뒤 2초쯤 지나야 바뀝니다.
  6. "로그인됐어요" 안내가 나오면 "정보 저장", "알림" 같은 창을 넘기고 끝내기를 누릅니다.
도움 버튼. ⌫ 지우기 전체 선택 Tab Esc ▲ 위로 ▼ 아래로 는 키보드 대신 씁니다. 엉뚱한 페이지로 갔다면 로그인 페이지로를 누르세요.
  • "Facebook 으로 로그인"은 쓸 수 없습니다. 인스타 아이디로 로그인하세요.
  • 원격 로그인은 최대 15분입니다. 화면을 90초 넘게 다른 앱으로 비워 두면 자동으로 끝납니다. 다시 누르면 이어서 할 수 있습니다.
  • 동시에 3명까지만 원격 로그인할 수 있습니다. 붐비면 잠시 뒤에 하세요.

4. 답장·공감 정하기

카드의 설정을 펼쳐서 적고 저장을 누릅니다. 30초 안에 반영됩니다.

칸적는 법
대상답장할 사람. DM 목록에 보이는 이름을 글자 하나 틀리지 않게 그대로, 한 줄에 한 명.
답장 보내기체크하면 답장을 보냅니다. 공감만 하고 싶으면 체크를 끄세요.
답장 문구한 줄에 하나. 여러 개 적으면 그중 하나를 무작위로 보냅니다.
하루 최대 답장1~50 (기본 20)
같은 사람 다시 답장까지(초)같은 사람에게 너무 자주 답하지 않게 하는 간격 (기본 120초)
보내기 전 대기(초)사람처럼 보이도록 잠깐 기다렸다 보냅니다 (기본 5~15초)
활동 시작·끝(시)답장하는 시간대 (기본 8시~23시). 22→6 처럼 적으면 밤새 동작합니다.

자동 공감

설정에서 자동 공감 누르기를 체크하면, 대상이 보낸 새 메시지마다 하트 같은 공감을 눌러 줍니다.

  • 이모지와 확률 — 아래 이모지 버튼을 누르거나 직접 입력하고 Enter 를 누르면 목록에 더해집니다. 이모지마다 확률(%)을 적으세요. 예: ❤️ 95, 😂 5 이면 메시지 100개 중 95개쯤은 하트, 5개쯤은 웃음입니다.
  • 합계가 100이 아니어도 적은 숫자의 비율대로 나눠서 고릅니다. 최대 8개까지 넣을 수 있습니다.
  • 하루 최대 공감 — 1~100 (기본 20).
  • 답장도 켜져 있으면 공감을 누른 뒤 이어서 답장합니다. 대상·대기 시간·활동 시간은 답장과 같이 씁니다.
  • 그 메시지에 이미 공감이 붙어 있으면 다시 누르지 않습니다. 1:1 대화에서만 공감합니다.
팁. 대상 이름이 안 맞으면 답장이 나가지 않습니다. 인스타 DM 목록에 보이는 이름을 그대로 복사해 붙이세요.

5. 켜고 기록 보기

  1. 대상을 적고, 답장 문구나 자동 공감 중 하나 이상을 켜서 저장했는지 확인합니다.
  2. 카드 오른쪽 위 스위치를 켭니다. 30초 안에 동작 중으로 바뀝니다.
  3. 카드의 기록을 펼치면 최근 100줄의 답장·공감 기록이 보입니다.

멈추려면 스위치를 끄면 됩니다. 계정을 아예 빼려면 계정 삭제를 누르세요. 그 계정의 로그인 정보와 기록도 함께 지워집니다.

6. 이럴 땐 이렇게

상황해결
"켜려면 대상을 넣고, 답장 문구나 자동 공감 중…"설정에 대상을 적고, 답장 문구를 넣거나 자동 공감을 체크해 저장한 뒤 켜세요.
공감이 안 눌려요① 자동 공감을 체크했는지 ② 오늘 최대 공감 수를 넘지 않았는지 ③ 기록에 "이모지를 못 찾음"이 있으면 다른 이모지로 바꿔 보세요. 계속되면 관리자에게 문의하세요.
답장이 안 나가요① 맨 위가 PC 연결됨인지 ② 대상 이름이 정확한지 ③ 활동 시간 안인지 ④ 오늘 최대 답장 수를 넘지 않았는지 보세요.
카드가 "로그인 필요"원격 로그인으로 인스타에 다시 로그인하세요.
"PC 가 아직 앞의 입력을 처리 중이에요"2~3초 기다렸다가 다시 누르세요.
"원격 로그인이 끝났어요"15분이 지났거나 화면을 오래 비웠습니다. 원격 로그인을 다시 누르세요.
"로그인 실패가 많아 15분 동안 잠겼어요"15분 뒤에 다시 로그인하세요.
사이트 비밀번호를 바꾸고 싶어요맨 아래 "비밀번호 바꾸기"를 펼쳐 바꾸세요. 바꾼 뒤 다시 로그인합니다.
